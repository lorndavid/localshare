# Changelog

## 1.0.0

- Automatic project, framework, TCP listener and Docker Compose port detection.
- One-click Cloudflare Quick Tunnel sharing with binary checksum verification and readiness checks.
- Multiple concurrent tunnels with an explicit state machine, restart recovery and orphan cleanup.
- Optional local password gateway, sensitive-service blocking and credential redaction.
- Cloudflare account connection, named tunnels, custom domains with DNS and HTTPS verification, and Cloudflare Access policies.
- Optional LocalShare Cloud metadata sync.
